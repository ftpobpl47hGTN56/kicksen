## What ChatsenKick can do

- **Real-time Kick chat:** receive messages anonymously and send messages after signing in with Kick OAuth.
- **Multiple channels:** open channels in tabs or add several usernames at once with one comma-separated line.
- **Saved channel list:** channels are stored locally in Hive; LIVE status, viewer count, category, and stream title are loaded through the official Kick API.
- **Emotes and badges:** Kick emotes, 7TV, BTTV, FFZ, subscriber badges, an emote picker, and consistent emote sizing in messages.
- **Replies and conversations:** reply threads, mentions, username autocomplete, user cards, and a searchable viewer list.
- **Media previews:** images, GIFs, videos, and link cards directly below messages.
- **Chat customization:** timestamps, font size, line separators, mention styles, filters, and ignored users.
- **Multiple Kick accounts:** sign in through the official Kick page and switch accounts when needed.
- **Chatsen Mod features:** local settings, channel history, notifications where supported, and backup/restore options.

## Installation

1. Download the APK from this release.
2. Open it and allow installation from your browser or file manager if Android asks for permission.
3. Add a Kick channel to start reading chat. Sign in with Kick OAuth only if you want to send messages.
